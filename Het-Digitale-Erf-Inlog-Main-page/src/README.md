# Het Digital Erf - Dashboard

Dashboard applicatie voor Het Digital Erf camping met modules voor reserveringen, bezetting, gasten, activiteiten, ziekteverzuim en meer.

## Installatie

1. Installeer dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open je browser op `http://localhost:5173`
